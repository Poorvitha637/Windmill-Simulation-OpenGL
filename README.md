# Windmill Simulation – OpenGL

An interactive 3D-style windmill farm simulation developed using C++ and OpenGL.

## Features
- Interactive camera rotation and zoom
- Day and night mode
- Animated rain and wind effects
- Night sky with stars
- Animated birds
- Flowers and scattered grass
- Weather HUD
- Pause and resume functionality

## Controls

| Key | Action |
|---|---|
| Left Mouse Drag | Rotate camera |
| Z / X | Zoom in / out |
| R | Toggle rain |
| D / N | Day / Night |
| S | Toggle stars |
| A | Toggle air flow |
| B | Toggle birds |
| F | Toggle flowers |
| G | Toggle grass |
| Space | Pause / Resume |
| Esc | Exit |

## Technologies
- C++
- OpenGL
- GLUT (FreeGLUT)
- Windows API

## Project Structure
- `main.cpp` – Main simulation source code

## Requirements
- Windows
- C++ compiler
- OpenGL development libraries
- GLUT / FreeGLUT

## How to Run
1. Install a C++ compiler and configure OpenGL and GLUT/FreeGLUT.
2. Create a C++ project in Code::Blocks.
3. Add `main.cpp` to the project.
4. Configure the required OpenGL and GLUT libraries.
5. Build and run the project.
